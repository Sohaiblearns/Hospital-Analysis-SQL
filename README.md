🏥 Hospital Analysis Using SQL

📌 Project Overview
This project analyzes hospital data using SQL to understand patient appointments, doctor performance, department activity, and treatment costs. The goal is to extract useful insights from hospital data and support better decision-making.

🎯 Project Objectives
- Analyze hospital appointments and patient records.
- Identify departments with the highest number of appointments.
- Analyze treatment costs and payment methods.
- Track appointment status and doctor activity.
- Practice SQL queries for real-world data analysis.

🗂️ Database Tables
The project contains four tables:

- Departments – Department details.
- Doctors – Doctor information and department assignments.
- Patients – Patient details.
- Appointments – Appointment records, treatment costs, and payment information.

🛠️ Tools Used
- MySQL – Database management and querying.
- SQL – Data analysis and insight generation.
- GitHub– Project documentation and portfolio.

🔍 SQL Concepts Used
- SELECT and WHERE
- ORDER BY and DISTINCT
- Aggregate functions (COUNT, SUM, AVG)
- GROUP BY and HAVING
- JOINs
- Subqueries
- CASE statements
- Date-based analysis

📊 Key Insights
- Analyzed 50 appointments across 30 patients.
- Cardiology recorded the highest number of appointments, with 9 appointments.
- Cardiology treatment costs totaled ₹62,200.
- Approximately 96% of appointments were completed.
- Insurance accounted for 55.2% of total treatment costs.
